# Triage labels

The `triage` skill names five roles. Each one is the label of the same name in this repo's issue tracker:

| Label | Meaning |
| --- | --- |
| `needs-triage` | The maintainer needs to evaluate this issue |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified, ready for an agent working alone |
| `ready-for-human` | Needs a person to implement it |
| `wontfix` | Won't be acted on |
