# Contributing

Mail Quilt isn't accepting pull requests yet. It's early, and one person builds it, so outside code would take longer to review than to write. For now, only the project's collaborators can open one.

Issues are welcome:

- **A bug.** Say what you did, what you expected, and what happened instead. Include the browser, the package and its version, and the email's JSON if it's part of the problem.
- **An idea or a question.** Check the [roadmap](https://github.com/yourcodebuddy-in/mailquilt/issues) first, since it may already be there.

This will change once the project can take outside work well. This page will say so.
