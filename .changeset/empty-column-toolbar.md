An empty Column's add buttons are one toolbar, named for where it is, such as "Add a Block to Row 1, Column 2". It's one stop for Tab, as the Block's and Row's toolbars are: the arrow keys go across its buttons, Home and End go to the first and last, and Shift+Tab leaves it. Each button is now named "Add Text Block here" and so on, without the Column, which the toolbar's name gives. Before, each empty Column was one Tab stop per type of Block.
