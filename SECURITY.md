# Security

## Reporting a vulnerability

Please don't report a security problem in a public issue. Report it privately through GitHub instead: [open a security advisory](https://github.com/mailquilt/editor/security/advisories/new). Only the maintainer can see it.

Say which package and version it affects, and how to reproduce it. You'll get a reply within a week. Once a fix is released, the advisory is published, with credit to you unless you'd rather not.

## Supported versions

Fixes go into the latest release of the `@mailquilt` packages. Mail Quilt is before `1.0`, so an older minor version doesn't get them.
