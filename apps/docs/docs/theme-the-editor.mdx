The editor doesn't take its colors or font from your page. It looks the same on any page until you set its [theme tokens](./theme-tokens), and then it uses yours. Set them on the `<mail-quilt>` element, or on `<mail-quilt-shell>` for a Shell.

## Your font and accent

Start with the font and the accent, which is enough for most apps:

```css title="styles.css"
mail-quilt {
  --mq-font-family: "Inter", system-ui, sans-serif;
  --mq-color-accent: #7c3aed;
  --mq-color-accent-strong: #6d28d9;
  --mq-color-accent-soft: rgb(124 58 237 / 10%);
  --mq-color-outline-hover: rgb(124 58 237 / 45%);
}
```

To change the frame beyond the tokens, such as for an editor that fills a panel edge to edge, style the `frame` part:

```css title="styles.css"
mail-quilt::part(frame) {
  border-radius: 0;
  box-shadow: none;
}
```

On a [Shell](./shell), the frame is the Shell's, so style `mail-quilt-shell::part(frame)` instead.

## A dark theme

The editor has a dark theme of its own. Turn it on with `theme`:

```html title="index.html"
<mail-quilt theme="dark"></mail-quilt>
```

- `light` is the default, and what the editor shows without `theme`.
- `dark` is the dark theme.
- `auto` follows the person's system, and changes when it does, such as when a laptop turns dark in the evening.

`theme` is an attribute and a property of `<mail-quilt>` and `<mail-quilt-shell>`, which passes it to the editor inside, and a prop of both React components.

In the dark theme, text meets WCAG AA's 4.5:1 against what it sits on, and focus rings and a field's edge meet 3:1. A field's edge is `--mq-color-border-strong`, 3.7:1 against `--mq-color-surface`. `--mq-color-border` is quieter, at 1.2:1, as it only separates areas such as toolbars and tiles, which don't need to stand out to be used. What the browser draws itself, such as the open list of a dropdown and the color picker, is dark too. Every value is in the Dark column of [theme tokens](./theme-tokens).

### Your colors in the dark theme

A token you set on the element wins over the dark theme, as it does over the light one. So a color you set for the light theme, such as the accent above, shows in the dark theme too. Give the dark theme its own by setting it for `[theme="dark"]`:

```css title="styles.css"
mail-quilt[theme="dark"] {
  --mq-color-accent: #9575f6;
  --mq-color-accent-strong: #c4b5fd;
  --mq-color-accent-soft: rgb(149 117 246 / 16%);
  --mq-color-outline-hover: rgb(149 117 246 / 50%);
  --mq-color-on-accent: #0f1115;
}
```

With `auto`, set them for `mail-quilt[theme="auto"]` inside `@media (prefers-color-scheme: dark)`. On a Shell, use `mail-quilt-shell` in place of `mail-quilt`. Set both accents in a stylesheet, as here: a token in the element's `style` attribute wins over any stylesheet, so a rule for `[theme="dark"]` can't replace it. The dark theme changes only colors and shadows, so the font, spacing and corners you set apply in both.

A few tokens pair with each other, so change them together, and keep text at 4.5:1 and a field's edge at 3:1:

- `--mq-color-surface` is also the icons and tag text on `--mq-color-text`, such as the selected Block's toolbar and tag. Keep the two far apart, one dark and one light.
- `--mq-color-on-accent` is the text on `--mq-color-accent`. With a light accent, as in the dark theme, it's dark.
- `--mq-color-accent` also outlines the selected Block on the email, and in the dark theme a Block with keyboard focus. The email is usually white, so keep the accent at 3:1 against white too, as `#9575f6` above is, at 3.4:1.
- `--mq-color-accent-strong` is the text, icons and edge of pressed buttons, such as Bold, on `--mq-color-accent-soft`. On a dark theme, make it lighter than the accent, not darker.
- `--mq-color-on-tooltip` is the text on `--mq-color-tooltip`.

The email itself stays as its sender designed it, with its own background, colors and font, because that's how it will look when it's sent. A white email on a dark workspace is expected.

Every token, with its default and what it changes, is on the [theme tokens](./theme-tokens) page.
