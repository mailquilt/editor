Mail Quilt is a free, MIT-licensed email builder that developers embed in their apps. It's a Web Component, `<mail-quilt>`, so it works in any framework, and it has a React wrapper.

- [Try the Playground](./playground) to design an email and export it, with nothing to install.
- [Quick start](./quick-start): add the editor to a page with a bundler, from a CDN, or in React.
- [Document format](./document-format): how an email is saved, and which values the editor accepts.
- [Tested email clients](./email-clients): where the exported HTML has been checked. Outlook is untested.
- [Roadmap](https://github.com/yourcodebuddy-in/mailquilt/issues): what's planned lives in GitHub Issues, where you can comment on it.

Mail Quilt is version `0.x`, so its API may still change between releases.
