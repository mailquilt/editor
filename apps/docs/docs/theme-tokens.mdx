The editor draws everything it owns from tokens: the workspace around the email, the Rows list, the Selection bar and its More panel, the Add panel and the picker, the toolbars on the canvas, Check's panel and the tooltips. Each token is a CSS custom property whose name starts with `--mq-`. Set one on the `<mail-quilt>` element, and the editor uses your value instead of its default.

```css title="styles.css"
mail-quilt {
  --mq-radius: 12px;
}
```

This page lists every token. [Theme the editor](./theme-the-editor) says which to set first, which ones pair with each other, and how to turn on the built-in dark theme.

The React component renders the same `<mail-quilt>` element, so the same selector works there. On a [Shell](./shell), set them on `<mail-quilt-shell>` instead. Its header and messages use them, and so does the editor inside it.

The frame around the editor, with its corners and its 1px ring, is the `frame` part. To change it beyond the tokens, style `mail-quilt::part(frame)`, such as `border-radius: 0` for an editor that fills a panel edge to edge. On a Shell, the frame is the Shell's, so style `mail-quilt-shell::part(frame)`.

The editor doesn't take its color, font or background from your page, so it looks the same on a light page and a dark one until you change a token or its `theme`. The defaults below are its light theme. With `theme="dark"`, or `theme="auto"` on a system set to dark, the color tokens and shadows take the values in the Dark column instead, and a token you set still wins over either.

The email itself never uses these tokens. The card in the middle of the canvas shows the email's own background color, font and width, which people change in the Selection bar with nothing selected, so it looks the way it will when it's sent. Check's inbox around the email is drawn as a mail client draws it, in the same colors in either theme, and none of them are tokens.

## Font

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-font-family` | `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", sans-serif` | The font of every control, label and tooltip. |
| `--mq-font-size` | `13px` | The size of text in the panel, the fields and the buttons. |
| `--mq-font-size-small` | `12px` | Hints, field descriptions and units, the link field's label and error, a Block's place under its name, an empty Column's placeholder, the names on tiles and thumbnails, and tooltips. |

## Spacing

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-space-1` | `4px` | The space between an empty Column's buttons, and other small gaps. |
| `--mq-space-2` | `8px` | The space between tiles, beside a Row and inside an empty Column, and the smaller padding of the Shell's header and messages, and in Check, the space beside Show sample values, under why a Problem matters and around its fix button. |
| `--mq-space-3` | `12px` | The padding at the Add panel's, the Rows list's and More's heads, beside the Rows list's pictures, at the Selection bar's ends, inside tiles and buttons with words, between settings side by side, and in Check, above the emails, between the inbox's sender and its lines, between one Problem and the next, and inside the note under a field a fix button focused. |
| `--mq-space-4` | `16px` | The padding of each group of settings, around the canvas, in the Shell's header, around Check's message while its email loads, beside the phone's Inbox link, and how far the floating toolbar sits from the bottom of the window. |
| `--mq-space-5` | `24px` | The space between the email and the floating toolbar, and in Check, the space between Show sample values and the emails, and between the two emails where they wrap. |
