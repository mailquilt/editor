The editor draws everything it owns from tokens: the workspace around the email, the side panel, the toolbars on the canvas and the tooltips. Each token is a CSS custom property whose name starts with `--mq-`. Set one on the `<mail-quilt>` element, and the editor uses your value instead of its default.

```css title="styles.css"
mail-quilt {
  --mq-font-family: "Inter", system-ui, sans-serif;
  --mq-color-accent: #7c3aed;
  --mq-color-accent-strong: #6d28d9;
  --mq-color-accent-soft: rgb(124 58 237 / 10%);
  --mq-color-outline-hover: rgb(124 58 237 / 45%);
  --mq-radius: 12px;
}
```

The React component renders the same `<mail-quilt>` element, so the same selector works there.

The editor doesn't take its color, font or background from your page, so it looks the same on a light page and a dark one until you change a token. The defaults below are a light theme. If you set darker colors, check that text stays readable against them.

The email itself never uses these tokens. The card in the middle of the canvas shows the email's own background color, font and width, which people change in the side panel's Settings tab, so it looks the way it will when it's sent.

## Font

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-font-family` | `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", sans-serif` | The font of every control, label and tooltip. |
| `--mq-font-size` | `13px` | The size of text in the panel, the fields and the buttons. |
| `--mq-font-size-small` | `12px` | Field labels, hints, descriptions, tooltips and the names under thumbnails. |

## Colors

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-color-workspace` | `#f1f2f5` | The background around the email card. |
| `--mq-color-surface` | `#ffffff` | The side panel, the toolbars, the tiles, the fields, the selected tab and an empty Column's placeholder. |
| `--mq-color-surface-muted` | `#f6f7f9` | The track behind the tabs, the wells behind tile icons, layout thumbnails and disabled fields. |
| `--mq-color-surface-hover` | `#eef0f3` | A button under the pointer. |
| `--mq-color-text` | `#18181b` | Text and icons, and the faint dots on the workspace. |
| `--mq-color-text-muted` | `#5b606a` | Field labels, hints, descriptions, units, icons at rest and tabs that aren't selected. |
| `--mq-color-border` | `#e6e8ec` | Borders around the panel, toolbars, tiles and tabs, and the rules between groups of settings. |
| `--mq-color-border-strong` | `#8c939d` | Borders of fields and of an empty Column's placeholder, and a lighter mix of it around layout thumbnails. |
| `--mq-color-accent` | `#2563eb` | The selected Block's outline and tag, focus rings, the selected tab's icon, the drop line and highlighted drop targets. |
| `--mq-color-accent-strong` | `#1d4ed8` | The outline of a Block with keyboard focus, and the text and icons of selected or pressed controls. |
| `--mq-color-accent-soft` | `rgb(37 99 235 / 10%)` | The background of pressed buttons, of the selected Block's type badge, of a Block with keyboard focus and of the Column a drop will land in, and the ring around a focused field. |
| `--mq-color-outline-hover` | `rgb(37 99 235 / 45%)` | The outline and tag of a Block under the pointer, the outline of a Row under the pointer, and of Columns while a Block is dragged. |
| `--mq-color-on-accent` | `#ffffff` | Text on an accent background, such as a Block's tag and the link field's Apply button. |
| `--mq-color-danger` | `#b91c1c` | Error messages, refused fields, and delete buttons under the pointer. |
| `--mq-color-tooltip` | `#18181b` | The tooltip's background. |
| `--mq-color-on-tooltip` | `#fafafa` | The tooltip's text. |

## Spacing

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-space-1` | `4px` | The space between an empty Column's buttons, and other small gaps. |
| `--mq-space-2` | `8px` | The space between tiles, beside a Row and inside an empty Column. |
| `--mq-space-3` | `12px` | The padding around the tabs, the side panel's header and inside tiles. |
| `--mq-space-4` | `16px` | The padding of each group of settings and the space between its fields, and how far the floating toolbar sits from the bottom of the window. |
| `--mq-space-5` | `24px` | The space between the email and the floating toolbar. |

## Corners and shadows

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-radius-small` | `6px` | The corners of buttons, fields, badges and tooltips. |
| `--mq-radius` | `10px` | The corners of toolbars, tiles, the tab track and the Preview. |
| `--mq-shadow-small` | `0 1px 2px rgb(16 24 40 / 8%)` | The shadow under the selected tab, a Block's drag handle and text buttons. |
| `--mq-shadow` | `0 1px 2px rgb(16 24 40 / 6%), 0 8px 24px -6px rgb(16 24 40 / 16%)` | The shadow under toolbars, tooltips, the Preview and a tile under the pointer. |
