The editor draws everything it owns from tokens: the workspace around the email, the side panel, the toolbars on the canvas and the tooltips. Each token is a CSS custom property whose name starts with `--mq-`. Set one on the `<mail-quilt>` element, and the editor uses your value instead of its default.

```css title="styles.css"
mail-quilt {
  --mq-radius: 12px;
}
```

This page lists every token. [Theme the editor](./theme-the-editor) says which to set first, which ones pair with each other, and has a complete dark theme.

The React component renders the same `<mail-quilt>` element, so the same selector works there. On a [Shell](./shell), set them on `<mail-quilt-shell>` instead. Its header and messages use them, and so does the editor inside it.

The frame around the editor, with its corners and its 1px ring, is the `frame` part. To change it beyond the tokens, style `mail-quilt::part(frame)`, such as `border-radius: 0` for an editor that fills a panel edge to edge. On a Shell, the frame is the Shell's, so style `mail-quilt-shell::part(frame)`.

The editor doesn't take its color, font or background from your page, so it looks the same on a light page and a dark one until you change a token. The defaults below are a light theme. For a dark one, set every color token, as the [dark theme](./theme-the-editor#a-dark-theme) does, and check that text stays readable.

The email itself never uses these tokens. The card in the middle of the canvas shows the email's own background color, font and width, which people change in the side panel's Settings tab, so it looks the way it will when it's sent.

## Font

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-font-family` | `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", sans-serif` | The font of every control, label and tooltip. |
| `--mq-font-size` | `13px` | The size of text in the panel, the fields and the buttons. |
| `--mq-font-size-small` | `12px` | Hints, field descriptions and units, the link field's label and error, a Block's place under its name, an empty Column's placeholder, the names on tiles and thumbnails, and tooltips. |

## Spacing

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-space-1` | `4px` | The space between an empty Column's buttons, and other small gaps. |
| `--mq-space-2` | `8px` | The space between tiles, beside a Row and inside an empty Column, and the smaller padding of the Shell's and the Preview's headers and of the Shell's messages. |
| `--mq-space-3` | `12px` | The padding around the side panel's tabs and header, inside tiles and buttons with words, between settings side by side, and between the parts of the Preview's header. |
| `--mq-space-4` | `16px` | The padding of each group of settings, around the canvas, in the Shell's and the Preview's headers, around the Preview's messages and beside its loading outline, above and below the email at Phone width, and how far the floating toolbar sits from the bottom of the window. |
| `--mq-space-5` | `24px` | The space between the email and the floating toolbar, the side padding of the narrow notice, and the space above and below the Preview's loading outline. |

## Corners and shadows

| Token | Default | What it changes |
| --- | --- | --- |
| `--mq-radius-small` | `6px` | The corners of buttons, tags, tooltips, drag handles, layout choices, an empty Column's placeholder and the fields. |
| `--mq-radius` | `10px` | The corners of the editor's and the Shell's own frames, and of tiles, toolbars, the tabs, the type badge, the Preview, the email at Phone width in the Preview and the narrow notice's icon. |
| `--mq-shadow-small` | `0 1px 2px rgb(22 24 29 / 8%)` | The shadow under a Block's drag handle, buttons with words, tiles, the settings fields, the selected tab, the chosen Preview width and the Preview's loading outline. |
| `--mq-shadow` | `0 0 0 1px rgb(22 24 29 / 4%), 0 2px 4px rgb(22 24 29 / 4%), 0 12px 32px -8px rgb(22 24 29 / 14%)` | The shadow under the email, a dragged Block or Row, toolbars, tooltips, the Preview, the email at Phone width in the Preview and the narrow notice's icon. |
